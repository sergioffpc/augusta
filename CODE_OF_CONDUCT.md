# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1: be respectful, accept constructive criticism gracefully, and focus on
what's best for the project.

Harassment, trolling, and personal attacks aren't tolerated. Instances of
unacceptable behavior may be reported to sergioffpc@gmail.com.
