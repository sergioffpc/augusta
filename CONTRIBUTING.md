# Contributing

This is a solo hobby project (see `README.md` / `docs/VISION.md`) without a
formal external contribution process. If you'd still like to contribute:

- Open an issue first for anything beyond a trivial fix, so scope can be
  agreed before you spend time on it.
- Follow the conventions in `docs/ENGINEERING.md` (code style, commit
  format, CI expectations).
- Commits must be signed and follow [Conventional Commits](https://www.conventionalcommits.org/).
- Branch off `develop`, not `main` (see `docs/ROADMAP.md` for the Git Flow
  layout); PRs target `develop`.

For anything else, open an issue or a discussion first.
