# Shading Language: Slang

Shaders are authored in Slang (Apache 2.0), already Falcor's default shader compiler and a transitive dependency. This formalizes it as an explicit, deliberate choice rather than an implicit side effect of picking Falcor.

## Consequences

Open consideration: pin to Falcor's vendored Slang version, or take an independent/newer version if a future need arises.
